## 📖 معرفی پروژه

**گرداننده مافیا (Dialogue)** یک دستیار هوشمند و تمام‌عیار برای برگزاری بازی محبوب **شهروند و مافیا** در جمع‌های دوستانه، خانوادگی و سفرهاست. این برنامه نیاز به کارت‌های فیزیکی، قلم و کاغذ و اتصال به اینترنت را به طور کامل برطرف می‌کند و تمام ابزارهای لازم برای یک گرداننده (گاد) حرفه‌ای را در محیطی ساده، سریع و تمام‌صفحه فراهم می‌سازد.

---

## ✨ ویژگی‌ها و امکانات کلیدی

* **📵 عملکرد ۱۰۰٪ آفلاین و مستقل:** اجرای کامل بدون کوچک‌ترین نیاز به اینترنت یا سرور خارجی؛ مناسب برای هر مکان و شرایطی.
* **🎲 توزیع تصادفی و عادلانه نقش‌ها:** تقسیم نقش‌ها بین بازیکنان به صورت کاملاً تصادفی و امن، همراه با نمایش مخفی نقش به هر بازیکن.
* **📋 پنل جامع مدیریت بازی (دستیار گاد):** نمایش لحظه‌ای لیست بازیکنان، وضعیت حیات یا خروج از بازی، و نقش هر فرد در طول شب و روز.
* **📱 تجربه کاربری بومی اندروید (Native Feel):**
  * اجرای کاملاً **تمام‌صفحه (Immersive Fullscreen)** بدون مزاحمت نوارهای بالای گوشی.
  * غیرفعال بودن زوم ناخواسته مرورگر و بهینه‌سازی‌شده برای صفحه‌نمایش‌های لمسی.
  * بهره‌گیری از فونت فارسی **وزیرمتن (Vazirmatn)** به صورت درون‌برنامه‌ای (آفلاین).
* **⚙️ تولید خودکار خروجی‌های رسمی (CI/CD):** کامپایل خودکار و امضاشده برای انتشار در مارکت‌های اندرویدی (`APK` و `AAB`) با مدیریت خودکار شماره نسخه.

## 📲 راهنمای دانلود و نصب روی اندروید

این اپلیکیشن بر روی **اندروید ۷.۰ (API 24) و بالاتر** قابل نصب و اجراست.

1. در منوی بالای همین صفحه، وارد تب **[Actions](https://github.com)** شوید.
2. آخرین اجرای موفق (دارای علامت تیک سبز ✅) را انتخاب کنید.
3. به پایین صفحه اسکرول کرده و از بخش **Artifacts**، بسته **`Mafia-Official-Release`** را دانلود کنید.
4. فایل ZIP دانلودشده را از حالت فشرده خارج کرده و فایل **`app-release.apk`** را روی گوشی خود نصب نمایید.

> **نکته هنگام نصب مستقیم:** در صورتی که فایل را مستقیماً (خارج از فروشگاه گوگل پلی) نصب می‌کنید، ممکن است سیستم امنیتی Google Play Protect پیام بررسی برنامه را نمایش دهد؛ کافی است گزینه **Scan app** (اسکن برنامه) یا **Install anyway** را انتخاب کنید تا نصب تکمیل شود.

## 🏗️ معماری و فناوری‌های استفاده‌شده

این پروژه بر پایه فناوری‌های مدرن وب ساخته شده و با استفاده از Capacitor به یک اپلیکیشن بومی اندروید تبدیل شده است:

| بخش | فناوری / ابزار | کاربرد در پروژه |
| :--- | :--- | :--- |
| **هسته برنامه** | TypeScript + Vite | توسعه سریع، سبک و بهینه رابط کاربری |
| **پوسته موبایل** | Capacitor (Android) | تبدیل پروژه وب به اپلیکیشن مستقل اندروید |
| **مدیریت بسته‌ها** | Bun | نصب سریع وابستگی‌ها و بیلد نسخه وب |
| **تایپوگرافی** | Vazirmatn (Variable) | نمایش استاندارد و آفلاین متون فارسی |
| **اتوماسیون ساخت** | GitHub Actions | تولید خودکار و امضاشده `APK` و `AAB` |

## 🛠️ راهنمای اجرا برای توسعه‌دهندگان (Local Development)

اگر قصد دارید کدهای پروژه را روی سیستم شخصی خود اجرا یا توسعه دهید، مراحل زیر را دنبال کنید:

</div>

```bash
# ۱. دریافت سورس‌کد پروژه از گیت‌هاب
git clone https://github.com

# ۲. ورود به پوشه پروژه
cd dialogue

# ۳. نصب پکیج‌ها و وابستگی‌ها با استفاده از Bun
bun install

# ۴. اجرای محیط توسعه (پیش‌نمایش در مرورگر)
bun run dev

# ۵. گرفتن خروجی نهایی نسخه وب (جهت انتقال به اندروید)
bun run build
```
